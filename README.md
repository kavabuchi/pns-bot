# pns-bot

Telegram-бот, который читает дедлайны из личного кабинета ПНС и присылает напоминания.

## Структура

```
main.py              точка входа: бот + хендлеры + планировщик
config.py            настройки из .env
bot/
  handlers/          команды: /start, /login, /deadlines
  texts.py           форматирование сообщений
  keyboards.py       кнопки
pns/
  client.py          вход на сайт ПНС и загрузка страниц
  parser.py          HTML -> list[Deadline]
  models.py          dataclass Deadline
storage/
  repository.py      Redis: пользователи и отметки «уже напомнил»
scheduler/
  jobs.py            периодическая проверка и рассылка
tests/               тесты парсера на сохранённом HTML
```

## Поток данных

```
планировщик -> repository (кто пользователи) -> pns.client (HTML) -> pns.parser (Deadline)
            -> сравнить со временем -> bot.send_message -> repository.mark_notified
```

## Этап 1. Разведка сайта ПНС (без кода)

Самый важный этап: от него зависит, как писать `pns/client.py` и `pns/parser.py`.

- [ ] Открыть ПНС в браузере, нажать F12 -> вкладка **Network**, поставить галочку **Preserve log**
- [ ] Выйти и снова войти в кабинет. Найти запрос, который отправляет логин/пароль. Записать:
  - URL запроса и метод (GET/POST)
  - какие поля отправляются (вкладка Payload)
  - какие cookie приходят в ответ (вкладка Headers -> Set-Cookie)
  - есть ли скрытые поля вроде `csrf_token` в форме входа
- [ ] Найти страницу, где видны задания и сроки. Записать её URL
- [ ] Понять, где лежат данные:
  - ПКМ -> «Просмотр кода страницы» (Ctrl+U): если дедлайны видны там — данные в HTML
  - если там пусто — ищи в Network (фильтр **Fetch/XHR**) запрос, который возвращает JSON
- [ ] Через инспектор (ПКМ по заданию -> «Проверить») найти теги/классы, где лежат название, предмет, дата
- [ ] Записать формат даты на сайте (например `15.11.2026 23:59`)
- [ ] Сохранить страницу с заданиями в `tests/fixtures/deadlines.html` (если данные в JSON — сохрани ответ в `deadlines.json`)

**Готово, когда:** у тебя есть записи (можно прямо в этот README в раздел «Заметки») и сохранённый файл страницы.
