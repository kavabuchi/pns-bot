# pns-bot

Telegram-бот, который читает дедлайны из календаря ПНС ХНЕУ (Moodle) и присылает напоминания.

## Как это работает

ПНС построен на Moodle. В Moodle есть **экспорт календаря**: постоянная ссылка, по которой
без логина и пароля отдаётся файл `.ics` со всеми событиями на ~60 дней вперёд.
Бот периодически скачивает эту ссылку, выбирает из событий дедлайны и напоминает о них.

```
планировщик -> repository (пользователи и их ссылки) -> pns.client (скачать .ics)
            -> pns.parser (выбрать дедлайны) -> сравнить со временем
            -> bot.send_message -> repository.mark_notified
```

## Структура

```
main.py              точка входа: бот + хендлеры + планировщик
config.py            настройки из .env
bot/
  handlers/          команды: /start, /link, /deadlines
  texts.py           форматирование сообщений
  keyboards.py       кнопки
pns/
  client.py          скачивание .ics по ссылке
  parser.py          .ics -> list[Deadline] (+ фильтр: что считать дедлайном)
  models.py          dataclass Deadline
storage/
  repository.py      Redis: пользователи, их ссылки, отметки «уже напомнил»
scheduler/
  jobs.py            периодическая проверка и рассылка
tests/               тесты парсера на сохранённом .ics
```
